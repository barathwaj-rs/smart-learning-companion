Smart Learning Companion

An AI-powered PDF learning assistant built using LangChain, Ollama, ChromaDB and Gradio.

Features
- Chat with PDF
- Generate Summaries
- Generate Quizzes
- Create Flashcards
- Generate Study Notes
- Build Glossaries

Tech Stack
- Python
- LangChain
- Ollama (Qwen3:8B)
- ChromaDB
- HuggingFace Embeddings
- Gradio
